# BackDown identity

The selected paired lowercase **bd** mark has been rebuilt as a clean vector and applied to the website and application sources.

- Production master: `../public/brand/backdown-mark.svg`.
- Website and app wordmark: lowercase **backdown**, using the existing Bricolage Grotesque brand typeface.
- Light colors: orange `#d8432b`, ivory `#f5f3ec`, charcoal `#17161b`; the website uses its existing brighter orange in dark mode.
- Website favicon, installed icons, social cards and demonstration screenshots use the same mark.

The website was deployed to **backdown.io** on 28 September 2026, Cloudflare version `c95ec481-9f44-4b43-a258-2209f78e07ae`, and the production logo, wordmark and versioned asset references were visually verified. App source changes require a future binary release to reach existing installations; this change did not publish an app release.

The original selected raster studies remain in `concepts/paired-bd-2026-09-28/`. Campaign deliverables are in `../campaigns/2026-09-launch/`.
