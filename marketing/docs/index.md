BackDown indexes your drives, finds what's duplicated across all of them, and tells you, with a SHA-256 hash behind every claim, which drives are safe to wipe. It runs on your own computer and only ever reads the drives it looks at, except when you ask it to copy into an archive, keep a mirror, or free up a drive.

New here? Start with [Getting started](/docs/getting-started/): install it, index two drives, see what's duplicated, and ask whether a drive is safe to wipe. [Concepts](/docs/concepts/) explains the ideas the rest of the docs rely on.

> [!NOTE]
> These docs describe the command-line preview and its web browser. The current download is v0.2.0-alpha.4; things marked **next preview** are built and come with the next release. The [status page](/status/) has what's released, what's next, and the plan to 1.0.
