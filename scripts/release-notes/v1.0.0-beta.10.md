The tenth beta of BackDown 1.0: two small corrections to beta.9's write-ahead log fix. If you're on beta.8 or earlier, this is the one to take.

beta.9 taught BackDown to reclaim the index's write-ahead log as it goes. But the reclaiming waited for readers the way a writer waits for its turn — up to 30 seconds — so one slow reader (a report, a stuck request) could hold a scan for 30 seconds at every batch, and every command for 30 seconds as it opened the index. It now waits a quarter of a second, long enough for a request in flight, and otherwise reclaims what it can and carries on. Opening the index also no longer writes to it when nothing has changed, so a command that only came to read no longer takes the writer's lock or leaves anything in the log.

## Install

| Platform | Installer | Command line |
|---|---|---|
| Linux x86-64 | `backdown-io_1.0.0-beta.10_amd64.deb` (Debian, Ubuntu) or `.AppImage` | `backdown-v1.0.0-beta.10-linux-x86_64.tar.gz` (static) |
| Linux ARM64 | `backdown-io_1.0.0-beta.10_arm64.deb` or `.AppImage` | `backdown-v1.0.0-beta.10-linux-arm64.tar.gz` (static) |
| macOS (Apple silicon + Intel) | `BackDown-1.0.0-beta.10.dmg` | `backdown-v1.0.0-beta.10-macos-universal.tar.gz` |

Windows builds are paused for this beta while the port is finished; follow it at <https://github.com/BuenGenio/BackDown/issues/94>.

**This release is signed.** `SHA256SUMS.txt.sig` is an Ed25519 signature of `SHA256SUMS.txt` by BackDown's release key, and `backdown update` checks it before installing anything. To check by hand, see [Air-gapped computers](https://backdown.io/docs/guides/air-gapped/).

The installers and apps themselves still aren't signed by Apple. On macOS, right-click the app and choose Open the first time (for the command-line binary: `xattr -d com.apple.quarantine backdown`).

## What's fixed since beta.9

- Reclaiming the write-ahead log waits a quarter of a second for readers, not the writer's 30 seconds: a slow reader no longer stalls a scan at every batch, nor every command as it opens the index.
- Opening the index writes nothing when the schema is already current, so commands that only read never take the writer's lock.
- Nothing else changed.

## Known limitations

- Reverse-geocoding is to the nearest populated place of 1,000+ people; a photo far from any town takes the nearest one, with lower confidence. The named-place and airport matches are within a set distance.
- The name index takes some room: on 8.5 million distinct names, about 1.2 GB.
- Searching another machine at its fastest needs beta.7 or later there too.
- The installers aren't signed or notarised by Apple.
- Windows builds are paused this beta while the port is finished (#94); Linux and macOS are unaffected.
- Pro, Team and Forensic features are free during the beta; pricing may change before 1.0.
