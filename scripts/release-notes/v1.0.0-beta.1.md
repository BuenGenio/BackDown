The first beta of BackDown 1.0: every feature planned for 1.0 is in. It finds out what's on your drives, what's duplicated, where it came from and which drives are safe to free, then helps you file everything into one archive, free the old drives and rescue failing ones. It runs locally and makes no network requests unless you ask.

## Install

| Platform | Installer | Command line |
|---|---|---|
| Linux x86-64 | `.deb` (Debian, Ubuntu) or `.AppImage` | `backdown-v1.0.0-beta.1-linux-x86_64.tar.gz` (static) |
| Linux ARM64 | `.deb` or `.AppImage` | `backdown-v1.0.0-beta.1-linux-arm64.tar.gz` (static) |
| macOS (Apple silicon + Intel) | `BackDown-1.0.0-beta.1.dmg` | `backdown-v1.0.0-beta.1-macos-universal.tar.gz` |
| Windows x86-64 | `BackDown-1.0.0-beta.1-x64.msi` (no administrator rights needed) | `backdown-v1.0.0-beta.1-windows-x86_64.zip` |

Open BackDown from your applications menu, or run `backdown app`: it starts BackDown in the background and opens it in its own window.

**These builds aren't signed yet.** On macOS, right-click the app and choose Open the first time (for the command-line binary: `xattr -d com.apple.quarantine backdown`). On Windows, SmartScreen may ask you to confirm once. Verify any download against `SHA256SUMS.txt`.

## What's new since v0.2.0-alpha.4

- **The app**: `backdown app` in its own window, desktop integration, installers for all three systems, a Settings view, and `backdown update` (checksum-verified, with rollback). Update checks are off unless you turn them on.
- **Drive health**: SMART readings without administrator rights, trends, warnings before a drive dies, desktop notifications, and "Copy it now" into Rescue.
- **Rescans in seconds**: from the drive's own change log (the USN journal on Windows, FSEvents on macOS) and by reading NTFS's file table directly, with a full scan whenever anything can't be vouched for. Free in every edition.
- **Free up drives**: tick what to wipe; a file is deleted only when an identical copy elsewhere is read back first; what exists only there is moved to a folder you choose.
- **Rescue**: copy a failing drive ddrescue-style, find deleted photos and documents by their content, find lost partitions, browse a found partition, and undelete files with their original names on FAT, exFAT and NTFS.
- **Browse without restoring**: mailboxes as threaded conversations, SQL dumps as schemas, the files inside disk images (FAT, exFAT, ext, NTFS), and search across every drive at once.
- **Where things came from, and when**: iPhone backups, Time Machine (including APFS), SQL dumps and backup scripts.
- **Several machines** (Pro, free during the beta): add a NAS or another computer over SSH; copies there count, carefully, as proof.
- **The archive**: fast verified copies, merging mailbox snapshots by Message-ID, and opt-in dedup inside the archive.
- **macOS and Windows**: case- and Unicode-safe names, long paths, NTFS alternate data streams, extended attributes, reading as a backup operator when elevated.

## Known limitations

- **This is the first release built without CI.** Every test passed on Linux, and the macOS and Windows builds were checked but not yet run on those systems. Please report anything that doesn't work.
- The builds aren't signed or notarised.
- Pro features are free during the beta; pricing may change before 1.0.
