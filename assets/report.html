Hash verification

Every file on the small drives was sha256-hashed, then matched against hashed twins on the 18 TB drive. Verified = an identical file exists on the big drive. Unique = no identical file anywhere else; must be copied before the drive is wiped.

Wipe verdicts

Nothing is wiped until every file has a sha256-verified copy. Hashing is complete on all drives; the 'copy first' sizes are the exact unique bytes.

Proposed filing

First level = type of thing, second = origin (host / person / company), third = time. One authoritative copy on the 18 TB drive; freed drives become mirrors of the irreplaceable subset.
